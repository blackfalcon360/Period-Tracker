# Period Tracker

پیریڈ کا ریکارڈ رکھنے والی ایپ — کیلنڈر، نوٹیفکیشن بار، ویجٹ، اور فون چلتے ہی خود نوٹیفکیشن۔

## ایپ کیا کرتی ہے
- کیلنڈر: درج شدہ پیریڈ، متوقع پیریڈ، بیضہ ریزی اور زرخیزی کی مدت کے اندازے (رنگوں میں)۔
- "آج پیریڈ شروع/ختم" کا ایک ٹیپ بٹن؛ کسی بھی دن پر ٹیپ کر کے شروع/ختم، بہاؤ، علامات اور نوٹ درج کریں۔
- ریکارڈ ٹیب: اوسط سائیکل، اوسط پیریڈ، آخری/اگلی تاریخ، فہرست اور علامات کا ریکارڈ۔
- نوٹیفکیشن بار میں مستقل نوٹیفکیشن (سائیکل کا دن اور اگلے پیریڈ تک دن)۔ فون ری اسٹارٹ، ایپ اپڈیٹ اور وقت بدلنے پر خود واپس آتا ہے؛ روزانہ 00:05 پر اپڈیٹ۔
- ہوم اسکرین ویجٹ۔
- لاک اسکرین پر تفصیل چھپانے کا آپشن (ڈیفالٹ: چھپی ہوئی)۔
- زبان: اردو / English / العربية؛ لائٹ اور ڈارک موڈ؛ باہر نکلنے سے پہلے تصدیق۔

## بِلڈ
1. فولڈر GitHub پر اپ لوڈ کریں۔
2. Actions میں "Build APK" چلے گا۔
3. Artifacts سے `PeriodTracker-APK` ڈاؤن لوڈ کریں۔

## پابندیاں
- صرف portrait؛ AndroidX یا بیرونی لائبریری نہیں؛ انٹرنیٹ نہیں؛ ڈیٹا صرف فون میں۔
- Android 13+ پر نوٹیفکیشن کی اجازت دینی ہو گی۔
- Android 14+ پر صارف مستقل نوٹیفکیشن ہٹا سکتا ہے؛ ایپ کھولنے یا ری اسٹارٹ/روزانہ اپڈیٹ پر دوبارہ آ جاتا ہے۔
- کچھ کمپنیوں (Xiaomi, Oppo, Vivo, Huawei) کے فون "Autostart" اور بیٹری آپٹیمائزیشن کی اجازت مانگتے ہیں، ورنہ ری اسٹارٹ پر نوٹیفکیشن نہ آئے۔
- پیشگوئیاں صرف اندازے ہیں؛ یہ مانع حمل یا طبی مشورہ نہیں۔
